## Featured Projects

### [Low-Cost Multispectral Pipeline for Distinguishing PLA from PET](https://github.com/Duke-Shawn/low-cost-multispectral-plastic-pipeline)
Classifies PLA vs PET plastics from spectral readings, aimed at informal recycling settings in Uganda where lab-grade sorting equipment isn’t affordable. It trains and compares PLS-DA, SVM, Random Forest and MLP models on public NIR/hyperspectral datasets (Plastic Scanner, HZDR Polymers), then reduces the wavelengths to what a low-cost multispectral sensor (AS7265x/AS7421-class) can measure. Evaluated with accuracy, macro-F1 and confusion matrices. The planned prototype runs on an ESP32.
